Internet Overview

The Internet is a global network of interconnected computer networks. Devices communicate using standard protocols such as TCP/IP, allowing information and services to move between networks.

Fundamental Computer Network Concepts

  • IP address: identifies a device/interface on a network.
  • Router: forwards packets between networks.
  • DNS: translates domain names into IP addresses.
  • HTTP/HTTPS: application protocols used to transfer web resources.
  • Packet: a unit of data carried through a network.

URL and its Structure

https://www.example.com:443/courses/web/index.html?year=2026#overview

  • https — scheme/protocol
  • www.example.com — host/domain
  • :443 — port
  • /courses/web/index.html — path
  • ?year=2026 — query string
  • #overview — fragment

Domain Name

A domain name is a human-readable web address used to identify a website, such as example.com. DNS maps the name to the IP address used for communication.

Web Browsers and Web Servers

Web Browser

Client software such as Chrome, Safari or Firefox. It sends requests, receives resources and renders HTML/CSS/JavaScript for the user.

Web Server

A system/software that receives HTTP requests and returns resources such as HTML, CSS, JavaScript, images or generated responses.

Working Principle of a Website

1. User
enters URL
2. DNS
finds server
3. Server
processes request
4. Browser
renders response

The browser may request additional CSS, JavaScript, images and media after receiving the initial HTML. The server can also communicate with databases or other services before returning a response.

Client-side vs Server-side Scripting

Client-side

  • Runs mainly in the user's browser.
  • JavaScript is a common example.
  • Useful for interaction and immediate UI updates.

Server-side

  • Runs on the web server.
  • Examples include Node.js, PHP, Python and Java server applications.
  • Useful for authentication, database access and server-generated responses.
